你正在继续开发 `portfolio-news-dashboard`，这是一个已部署在 Ubuntu + Nginx 的中文个人投资工作台，生产路径为 `/portfolio/`。

请先阅读 `README.md`、数据类型定义和所有业务 section，再检查当前 Git 状态与最近提交。保留现有用户数据兼容性，不要修改或清空浏览器 localStorage key。当前页面中的种子内容只是设计示例，不是真实行情或结论。

本轮目标：根据我随后提供的标的、字段和数据源，把“持仓新闻”从手动记录升级为可追溯的数据流。开始编码前先输出一份短设计，明确：

1. 数据源名称、授权方式、速率限制、覆盖市场与使用成本；
2. 每条新闻的原始标题、原文 URL、来源、原始发布时间、抓取时间、关联标的和去重键；
3. 服务端抓取、缓存、定时刷新、失败重试与前端读取的边界；
4. 摘要与情绪标签如何区分事实和模型判断，并保留证据链接；
5. 用户认证、服务端持久化和旧 localStorage 数据迁移方案；
6. 待补数据和无法可靠判断时的页面表现。

实现要求：

- 不得从模型记忆补全事实，不得把示例数据标成实时数据；
- 新闻需按持仓代码过滤，支持时间窗口、来源和重要性筛选；
- UI 使用中文投资研究语言，优先展示“发生了什么、为何影响持仓、需验证什么”；
- 密钥只放服务器环境变量或 AWS Secrets Manager，不写入代码、日志或 Git；

- 部署前保留现有 Nginx 服务和其他进程，部署后用桌面和手机视图验证外部链接；
- 提交只包含本项目的相关改动。
